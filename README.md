# WatchAI: вопрос на часах → локальный ИИ на телефоне → ответ на часы

Два приложения:

- **WatchAI-watch.apk** (Wear OS, Samsung Galaxy Watch 8): кнопка «🎤 Спросить» (голос) или «⌨ Текстом». Вопрос уходит на телефон, ответ приходит обратно и показывается на экране (или уведомлением, если приложение закрыто).
- **WatchAI-phone.apk** (Android): принимает вопрос, отправляет его в локальный ИИ по OpenAI-совместимому API и возвращает ответ на часы.

```
часы (голос) ──Bluetooth/Wi-Fi──▶ телефон ──HTTP──▶ локальный ИИ
часы (ответ) ◀──────────────────── телефон ◀───────── ответ
```

## Где взять APK

На странице **Releases** репозитория, релиз `watchai-latest`. Он пересобирается автоматически при каждом пуше в ветку `watch-ai` (GitHub Actions).

## Установка

### 1. Телефон

Скачай `WatchAI-phone.apk`, установи (разреши установку из браузера/файлов). Открой приложение:

1. Укажи адрес ИИ (см. ниже) и, при необходимости, модель.
2. Нажми «Проверить связь с ИИ»: должен прийти ответ.
3. Включи «постоянный режим»: так система не убьёт приложение, пока ИИ думает.
4. В настройках Android отключи для приложения оптимизацию батареи (иначе фон может засыпать).

### 2. Часы (Galaxy Watch 8)

Часы должны быть сопряжены с телефоном (приложение Galaxy Wearable). Установка APK по Wi-Fi через `adb`:

1. На часах: Настройки → О часах → Программное обеспечение → 5 раз нажать «Версия ПО» (режим разработчика).
2. Настройки → Параметры разработчика → включить «Отладка ADB» и «Отладка по Wi-Fi».
3. Там же нажать «Подключить новое устройство», получишь IP:порт и код.
4. На компьютере с `adb`:
   ```
   adb pair IP:ПОРТ_ПАРЫ        # ввести код
   adb connect IP:ПОРТ
   adb install WatchAI-watch.apk
   ```
5. Открой на часах «Спросить ИИ», разреши уведомления.

Важно: приложения для часов и телефона имеют один пакет `com.watchai.app` и одну подпись, иначе часы и телефон не смогут обмениваться сообщениями. Ставь оба APK из одного релиза.

## Какой «локальный ИИ» подходит

Любой сервер с OpenAI-совместимым `/v1/chat/completions`:

| Где запущен ИИ | Адрес в приложении |
|---|---|
| Ollama на компьютере в той же Wi-Fi сети | `http://192.168.x.x:11434/v1` |
| LM Studio на компьютере | `http://192.168.x.x:1234/v1` |
| llama.cpp `llama-server` в Termux на самом телефоне | `http://127.0.0.1:8080/v1` |
| Ollama в Termux на телефоне | `http://127.0.0.1:11434/v1` |

Для Ollama на компьютере запусти её с `OLLAMA_HOST=0.0.0.0`, чтобы телефон мог подключиться. В поле «Модель» впиши имя, как в `ollama list` (например `qwen2.5:7b`).

## Сборка

Автоматически: GitHub Actions (`.github/workflows/build.yml`). Локально нужен Android SDK:

```
./gradlew :phone:assembleRelease :wear:assembleRelease
```

Ключ подписи хранится в секретах репозитория (`KEYSTORE_B64`, `KEYSTORE_PASSWORD`). Без него workflow создаёт временный ключ, но тогда при каждой новой сборке приложения придётся удалять и ставить заново.
